# ai-trade-check — AI に株の売買判断をさせたら、指数に勝てるのか？ をペーパートレードで検証するツール

日本株（東証）を対象に、毎日の売買判断を「判断エンジン」に任せ、仮想の資金で記録するツールです。過去の期間をまとめて再生（リプレイ）して、全世界株・日経平均と成績を比べられます。

検証の経緯と結果は、note の解説記事にまとめています：[AI株自動売買をJevで検証｜「AIで資産が何倍にも」は本当？](https://note.com/shisaku_lab/n/n37168212bd20)

## 結論（先に）

- 2025年以降の上げ相場では、指数並みかそれ以上の成績に見える戦略もありました
- ただし 10年・税込みで見ると、試したモメンタム戦略は全世界株に大きく負けました
- お金を増やす本命は指数で、このツールは実験用です

詳しい数字は「検証結果」に載せています。

## ご注意（免責）

- このツールは投資助言ではありません。売買のシグナルやおすすめ銘柄を提供するものではありません
- 過去の検証結果は、将来の成績を保証しません
- 実際の売買には使わない前提の、学習・検証用のツールです
- 株価データは yfinance で取得しています。データの再配布はしません（このリポジトリにはデータを含めていません）
- 適時開示の取得には、第三者の非公式 API（webapi.yanoshin.jp）を使っています。利用はその提供元の条件に従ってください

## 使い方

### 準備

1. Python 3.10 以上を用意します
2. 依存パッケージを入れます

```
pip install -r requirements.txt
```

3. `config.example.json` を `config.json` にコピーして、必要なら編集します（コピーしなければ、見本のまま動きます）

### 過去の期間をリプレイする（ダミーのエンジン）

```
python main.py --replay 2025-01-06 2025-09-26 --engine dummy --db replay.db
```

`--replay` には開始日と終了日（YYYY-MM-DD）を渡します。`--db` は記録先の SQLite ファイルです。

### モメンタム戦略

```
python main.py --replay 2025-01-06 2025-09-26 --engine dummy --strategy momentum --db momentum.db
```

`--strategy` は `ai`（エンジンが売買を判断）か `momentum`（モメンタム＋エンジンの拒否権）を選びます。

### コアETFなし

```
python main.py --replay 2025-01-06 2025-09-26 --engine dummy --no-core --db nocore.db
```

`--no-core` を付けると、待機資金をコアETFに置きません。

### 損失上限なし（検証用）

```
python main.py --replay 2025-01-06 2025-09-26 --strategy momentum --no-loss-limit --db noloss.db
```

1日・累計の損失上限による停止を無効にします（`--replay` のときだけ有効）。

### 買い方の切り替え

`--entry open`（翌日寄付きで成行）か `--entry dip`（押し目指値）で、`config.json` の `entry.buy` を上書きできます。

### 結果を比べる

```
python compare.py replay.db momentum.db nocore.db
```

リプレイの DB を並べて渡します。同じ設定を複数回回した分は `+` でつなぎます。

### ダッシュボード

```
python server.py
```

ブラウザで http://127.0.0.1:8768/ を開きます（`start.bat` でも起動できます）。`--port`、`--db`、`--no-browser` も使えます。

## 判断エンジン

既定はダミーです。5日線と25日線のクロス＋RSI で判断するので、誰でも同じ結果を再現できます。

自分の AI（LLM の API など）を使いたい場合は、`ai_engine.py` を次のように変えます。

1. `ask_ai(state)` を実装する
2. `AI_READY = True` にする
3. `--engine ai` を付けて実行する

- 入力 `state`：銘柄・特徴量・持ち高をまとめたデータです
- 返す形：`(action, confidence, raw)`
  - `action`：`"buy"`、`"sell"`、`"hold"` のどれか
  - `confidence`：確信度（0〜1）
  - `raw`：生の応答の文字列（記録用）

呼び出しに失敗したときや、想定外の回答が返ったときは、安全側の `hold` になります。なお `AI_READY` が `False` のあいだは、`ai` を選んでもダミーで判断します。

モメンタム戦略の「拒否権」を使う場合は、`veto(state)` も同じように実装します（既定は止めません）。

## 検証結果

2026-09-28 時点、元本100万円、税金を含みません。

| 期間 | 設定 | リターン | 最大下落率 |
|---|---|---|---|
| 2025-01〜2026-09 | 外部の AI が30銘柄を判断（2回の平均）※ | +38.0% | 7.1% |
| 同 | モメンタムのみ | +52.1% | 10.0% |
| 同 | モメンタム＋外部の AI の拒否権（2回の平均）※ | +41.4% | 10.6% |
| 同 | SMAクロス＋コアETF | +43.1% | 23.0% |
| 同 | 全世界株（ACWI・円換算）／日経平均 | +36.1%／+68.8% | 20.1%／22.3% |
| 2016-01〜2026-09 | モメンタムのみ（損失上限なし） | +24.5%（年率+2.1%） | 27.9% |
| 同 | 全世界株（ACWI・円換算） | +287.7%（年率+13.4%） | 33.4% |

※ の行は、早期アクセスで利用した外部の AI サービスで判断した結果です。公開版のコードでは再現できません（自分の AI をつなげば、同じ流れで試せます）。

- 税金（特定口座・源泉徴収ありと同じ20.315%、`costs.tax_rate`）を入れると、モメンタムのみは2025年〜で+41.2%、10年で−2.6%に下がります。指数は売るまで税金がかからず、NISA なら非課税なので、実際の差はさらに開きます
- 外部の AI の結果は、同じ設定でも回すたびに±7%程度ぶれました。1回の数字で判断しないでください
- 2025年以降の好成績は上げ相場の影響が大きく、10年で見ると、試したモメンタム戦略は指数に大きく負けました
- 外部の AI の「拒否権」は、モメンタムの成績を下げました
- 気をつけたこと（データの落とし穴）
  - あとから選んだ銘柄で検証しています（生存バイアス）
  - AI が過去の値動きを覚えている可能性があります（未来の情報が混ざるおそれ）

## フォルダの中身

| ファイル | 役割 |
|---|---|
| `main.py` | 実行の入口。日次の判断とリプレイ |
| `ai_engine.py` | 判断エンジン（ダミー、自分の AI をつなぐ場所） |
| `broker/paper.py` | 仮想の売買（ペーパー）の約定・コスト計算 |
| `risk.py` | 売買前のリスク確認（損失上限など） |
| `store.py` | SQLite への記録 |
| `data.py` | 株価データの取得 |
| `features.py` | 判断に使う特徴量の計算 |
| `compare.py` | リプレイ結果の比較 |
| `server.py` | ダッシュボードのサーバー |
| `dashboard.html` | ダッシュボードの画面 |
| `test_*.py` | テスト |

データベース（`*.db`）とログ（`*.log`）は実行すると作られます。Git には含めません。
